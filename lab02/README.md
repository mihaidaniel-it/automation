## Задание

Написать Python-скрипт `currency_exchange_rate.py`, который взаимодействует с API сервиса курсов валют (проект `lab02prep`):

1. Получает курс одной валюты к другой на указанную дату. Валюты и дата передаются параметрами командной строки;
2. Сохраняет полученные данные в JSON-файл в директории `data/` в корне проекта (`lab02/`). Имя файла содержит валюты и дату запроса;
3. Обрабатывает ошибки при обращении к API (неверные параметры и т.д.), выводит понятные сообщения в консоль и записывает их в `error.log` в корне проекта (`lab02/error.log`).

Сервис содержит данные за период `2025-01-01` — `2025-09-15`. Поддерживаемые валюты: `MDL`, `USD`, `EUR`, `RON`, `RUS`, `UAH`.

## Подготовка

### 1. Запуск сервиса

Нужны Docker и Docker Compose. В директории проекта `lab02prep`:

```bash
cp sample.env .env
docker-compose up --build -d
```

Сервис будет доступен по адресу `http://localhost:8080`. API-ключ задаётся в файле `.env` (по умолчанию `EXAMPLE_API_KEY`).

### 2. Установка зависимостей

Требуется Python 3.8+. Скрипт использует библиотеку `requests`.

```bash
cd lab02
python3 -m venv .venv
source .venv/bin/activate
pip install requests
```

## Запуск скрипта

```text
python currency_exchange_rate.py ИЗ_ВАЛЮТЫ В_ВАЛЮТУ ДАТА [--url URL] [--key KEY]
```

| Параметр        | Описание                                                             |
|-----------------|----------------------------------------------------------------------|
| `from_currency` | из какой валюты конвертация (пр.: `USD`), регистр не важен           |
| `to_currency`   | в какую валюту конвертация (пр.: `EUR`)                              |
| `date`          | дата в формате `YYYY-MM-DD` в периоде `2025-01-01` … `2025-09-15`    |
| `--url`         | адрес сервиса; по умолчанию `$API_URL` или `http://localhost:8080/`  |
| `--key`         | API-ключ; по умолчанию `$API_KEY` или `EXAMPLE_API_KEY`              |

Команды запускаются из папки `lab02`. Курс округляется до двух знаков после запятой. Справка по параметрам: `python currency_exchange_rate.py -h`.

В PyCharm параметры задаются в **Run → Edit Configurations… → Script parameters**, например `USD EUR 2025-04-23`.

### Пример

```bash
python currency_exchange_rate.py USD EUR 2025-04-23
```

```text
Запрос данных для: USD/EUR для 2025-04-23...
Разница между валютами: USD -> EUR = 1.15
Данные сохранились в: .../lab02/data/USD_EUR_2025-04-23.json
```

Содержимое `data/USD_EUR_2025-04-23.json`:

```json
{
    "from": "USD",
    "to": "EUR",
    "rate": 1.15,
    "date": "2025-04-23"
}
```

Передача ключа через переменную окружения:

```bash
API_KEY=EXAMPLE_API_KEY python currency_exchange_rate.py eur mdl 2025-06-15
```

> Поле `rate` — значение сервиса, округлённое до двух знаков. Сервис считает его как `курс_TO / курс_FROM` (оба курса — в MDL).

### Тестовые запуски

Курс `USD → EUR` получен для 5 дат с равным интервалом в 1 месяц (23-е число каждого месяца):

```bash
for d in 2025-04-23 2025-05-23 2025-06-23 2025-07-23 2025-08-23; do
    python currency_exchange_rate.py USD EUR "$d"
done
```

| Дата       | Курс | Файл                           |
|------------|------|--------------------------------|
| 2025-04-23 | 1.15 | `data/USD_EUR_2025-04-23.json` |
| 2025-05-23 | 1.13 | `data/USD_EUR_2025-05-23.json` |
| 2025-06-23 | 1.15 | `data/USD_EUR_2025-06-23.json` |
| 2025-07-23 | 1.17 | `data/USD_EUR_2025-07-23.json` |
| 2025-08-23 | 1.16 | `data/USD_EUR_2025-08-23.json` |

### Обработка ошибок

Каждая ошибка выводится в консоль (stderr) и дописывается в `error.log` с временной меткой; скрипт завершается с ненулевым кодом.

| Команда                                               | Сообщение                                                                           |
|-------------------------------------------------------|-------------------------------------------------------------------------------------|
| `... USD EUR`                                         | `Ошибка: ожидается 3 аргумента: ИЗ_ВАЛЮТЫ В_ВАЛЮТУ ДАТА`                            |
| `... U5D EUR 2025-03-01`                              | `Ошибка: неверный код валюты 'U5D'. Используйте код из 3 букв, пр.: USD.`           |
| `... USD EUR 2025-13-01`                              | `Ошибка: неверная дата '2025-13-01'. Используйте формат YYYY-MM-DD.`                |
| `... USD EUR 2005-06-23`                              | `Ошибка: дата 2005-06-23 вне периода. Доступные данные: 2025-01-01 .. 2025-09-15.`  |
| `... USD XYZ 2025-03-01`                              | `Ошибка: сервис ответил: The currency XYZ is unknown`                               |
| `... RUS MDL 2025-03-01`                              | `Ошибка: сервис ответил: Unknown currency rus`                                      |
| `... USD EUR 2025-03-01 --key WRONG`                  | `Ошибка: сервис ответил: Invalid API key`                                           |
| `... USD EUR 2025-03-01 --url http://localhost:9999/` | `Ошибка: Не запущен http://localhost:9999/`                                         |

Пример `error.log`:

```text
[2026-10-01 13:31:25] Ошибка: неверная дата '2025-13-01'. Используйте формат YYYY-MM-DD.
[2026-10-01 13:31:25] Ошибка: дата 2005-06-23 вне периода. Доступные данные: 2025-01-01 .. 2025-09-15.
[2026-10-01 13:31:26] Ошибка: сервис ответил: Invalid API key
```

> Скрипт сам проверяет период дат, потому что на дату вне периода (например, 2005 год) сервис не выдаёт ошибку, а молча возвращает один и тот же курс по умолчанию.
>
> Валюта `RUS` объявлена в сервисе, но в его данных курс хранится под ключом `rub`, поэтому сервис всегда возвращает для неё ошибку.

## Структура скрипта

```text
lab02/
├── data/                       # JSON-файлы с результатами (создаётся автоматически)
├── error.log                   # журнал ошибок
├── currency_exchange_rate.py
└── README.md
```

Основные функции `currency_exchange_rate.py`:

- **`get_arguments()`** — валидация вводных данных:
  - создаёт парсер `argparse` и описывает параметры `from_currency`, `to_currency`, `date` и необязательные `--url`, `--key` (их значения по умолчанию берутся из переменных окружения `API_URL`/`API_KEY` или из констант в скрипте);
  - если аргументов меньше трёх, записывает ошибку в `error.log` (сам `argparse` пишет ошибку только в консоль);
  - переводит коды валют в верхний регистр и проверяет, что каждый состоит из 3 букв;
  - проверяет формат даты `YYYY-MM-DD` и что дата входит в период данных сервиса;
- **`get_exchange_rate(url, key, from, to, date)`** — отправляет `POST`-запрос к сервису: валюты и дата передаются в query-строке, ключ — в теле запроса (`key=...`). Обрабатывает ошибки сети (сервис не запущен, долгое ожидание, HTTP-ошибки), некорректный JSON и поле `error` в ответе (сервис всегда отвечает кодом 200, а ошибку передаёт в этом поле). Возвращает поле `data`, курс в нём округлён до двух знаков после запятой;
- **`save_to_json(data)`** — создаёт директорию `data/`, если её нет, и сохраняет ответ в файл `<FROM>_<TO>_<DATE>.json`;
- **`log_error(message)`** — выводит сообщение в консоль (stderr) и дописывает его с временной меткой в `error.log`;
- **`fail(message)`** — добавляет к сообщению префикс `Ошибка:`, вызывает `log_error` и завершает скрипт с кодом 1;
- **`main()`** — последовательно вызывает функции выше и выводит курс и путь к сохранённому файлу.
